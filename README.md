# MuPlash: Music Ripple Synthesizer

Interactive Fluid Simulation & Music Synthesizer for iOS.

## 🎵 About MuPlash
MuPlash is an interactive iOS application that simulates realistic liquid ripples with real-time sound synthesis powered by Apple Metal and Accelerate framework.
